# QR-Code-Generator
A simple Python-based project that generates QR codes for text, links, or any custom data instantly. It uses Python libraries to create and save QR codes as image files, making it useful for sharing information quickly and securely.

## Features

- Generate QR codes instantly
- Supports text, links, and custom data
- Saves QR code as an image
- Simple and beginner-friendly Python project

---

## Technologies Used

- Python
- Python IDLE
- qrcode Library

---

## Applications

- Website Links
- Digital Payments
- Contact Sharing
- Event Registration
- Product Information
